TaskManager – C++ Project
A simple C++ task management system built to practise classes, vectors, and basic object‑oriented design.
The project includes a TaskManager class that stores tasks, allows adding, removing, renaming, marking completion, and searching.

🧩 Features
TaskManager
Manages a list of tasks using std::vector.

Supported operations:

Add a task  
Adds a new task (empty names allowed if desired).

Remove a task  
Removes a task by index (safe handling of invalid indexes).

Mark a task as completed  
Marks a task as done.

Rename a task  
Changes the name of an existing task.

Find a task  
Searches for a task by name and returns its index or -1.

Print tasks  
Displays all tasks with their completion status.
