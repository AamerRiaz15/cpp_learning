F1 Class – Constructor & Basic OOP Example
This exercise demonstrates the fundamentals of object‑oriented programming in C++.
It focuses on creating a simple class (F1) that models a Formula 1 car with basic behaviour and internal state.

The goal of this program is to practice:

defining a class

using private data members

writing public methods to modify state

implementing a constructor with default parameters

using an initializer list

creating an object in main()
