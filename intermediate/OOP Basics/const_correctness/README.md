# C++ Player Class (Beginner OOP Practice)

This project demonstrates beginner-level Object-Oriented Programming in C++.  
It includes a simple `Player` class with a constructor, destructor, getter, setter, and proper const-correctness.

## Features
- Private member variable (`name`)
- Constructor using an initializer list
- Destructor showing object lifetime
- Const getter (`get_name`)
- Setter (`set_name`)
- Passing objects by const reference

## Purpose
This code is part of learning core OOP concepts such as encapsulation, object lifetime, and const correctness.

## Example
The program creates two Player objects (`villain` and `hero`) and prints their names, calling the destructor when objects go out of scope.
